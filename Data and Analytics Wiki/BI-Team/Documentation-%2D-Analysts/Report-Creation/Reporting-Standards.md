### Colours



#### Negative

Negative values within a report should be denoted by the use of <font color="#F47C20">**Orange**</font>, primarily, with the key negative values as the <font color="#F47C20">**#F47C20**</font> hex code from the Te Pātaka theme.

### Numbers

Any whole number should be comma separated i.e. 1,414 for better readability.

### Info Icons and Subtitles
The (I) icon should be used where explanation is needed for a card, kpi or new card visual. Subtitles are great for adding explanation for another type of barchart or similar visual where a one liner of text is needed to understand what the visual is showing.

### Selection

Relevant components of the page should be ordered top to bottom how you would expect them to be in terms of Layer Order, Grouping where it makes sense. By default, the Theme should have things like the Footer Grouped as this should be static (the footer contains the Selected filters area box as well as the developed by link.

# Fabric Conversion - Overview

Moving the Synapse / Azure Data Factory source loads to Microsoft Fabric. Each data source is loaded **as received** into the bronze lakehouse (`lh_bronze`) by PySpark notebooks, started by a Fabric pipeline.

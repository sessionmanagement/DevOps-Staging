# Adaptive Test Framework (ATF)

The Adaptive Test Framework (ATF) v1.0 is the configurable, project-agnostic productisation of the Enterprise Testing Framework (ETF) v2.0 methodology. It is a set of GitHub Copilot agents and task prompts, a governance rulebook, and a project data layer, used inside VS Code.

It is for Emerge test analysts and the wider BI team. Use it to plan, design, support the execution of, report on, and govern UAT and integration testing of vendor-delivered solutions, with AI assistance.

The agents help you plan, write, organise and report. You and the test team run the actual tests. The agents do not click buttons in the system under test.

The methodology and the agents are fixed framework IP. Everything organisation- or project-specific lives in the project data layer as configuration. You set that up by running one agent, with zero edits to the framework IP.

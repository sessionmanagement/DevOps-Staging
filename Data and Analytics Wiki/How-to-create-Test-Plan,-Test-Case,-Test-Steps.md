# Benefit
1. Organise all the test cases in one place.
2. A quick overview on the status of the test cases.
3. Create bug tickets while testing with all info during testing.

# Pre-requisite
1. Azure DevOps Test Plan license.
2. Understand the hierarchy of the test plan in Azure DevOps.
3. Understand what you test, ie software, KPI, Data Warehouse.

Steps
1. Create Test Plan. Data and Analytics -> Test Plans -> Test Plans -> New Test Plan -> Type Name/Area Path/Iteration -> Click Create
2. Create Test Suite. Create User Story in Boards -> Go to the test plan -> New Suite -> Static suite for Top Level folder / Requirement based suite for test suite -> Select the suite -> New Test Case -> Type a title -> Add test steps
3. Create Test Steps. Click or type here to add a step -> add steps one by one / Insert shared steps -> Run query -> select the right shared steps -> Insert shared steps.
4. Create Shared Steps. Select all steps -> Create shared steps.

# Benefit
1. Give you a visual view of the current project progress, when catching up with the manager.
2. Low maintenance, once set up no need to maintain, unless changing the dashboards.
3. Stands out. Not many people are using Azure DevOps Dashboards. 

# Pre-requisite 
1. Access to create new dashboard on the Azure DevOps.
2. Able to create queries.
2. Able to design the dashboard.

# Steps
1. Create queries. Boards -> Queries -> New queries.
2. Create a new dashboard. Overview -> Dashboards -> New dashboard -> Name/Description/Team dashboard or Project dashboard -> Create.
3. Insert widgets. Add a widget -> Query Tile / Query Results -> Add -> Title/Query/Default background color -> Save.
